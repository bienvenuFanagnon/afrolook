# Contes d'histoire : sources consultées (octobre 2026)

Les 18 contes d'histoire de la vague 2 ont été confrontés à des sources en ligne ; les textes ont été corrigés quand les sources les contredisaient ou ne les confirmaient pas.
Les sources ci-dessous sont des synthèses encyclopédiques et institutionnelles ; pour un usage scolaire, un recoupement avec un ouvrage d'historien reste conseillé.
