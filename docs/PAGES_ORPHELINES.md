## Comment décider
- **Supprimer** : le fichier entier n'est plus utile.

Après décision : supprimer, lancer `flutter analyze lib`, vérifier qu'aucun symbole supprimé n'est encore référencé, puis noter dans `docs/PROJET_MEMOIRE.md` (journal).
