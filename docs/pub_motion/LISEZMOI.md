# Pub motion Afrolook (32 s, 1080×1920)
Source : index.html (animation pilotée par `render(t)`), music.py (musique + effets), render.js (Playwright : une capture par image).
Rendu : `npm i playwright-core`, `node render.js full`, `python3 music.py`, puis ffmpeg (30 i/s, H.264 + AAC).
Le fichier final est docs/Afrolook_Pub_32s.mp4 (non versionné : exclu du dépôt).
