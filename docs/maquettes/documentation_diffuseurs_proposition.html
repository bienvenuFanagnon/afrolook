Afrolook Ads · Diffuseurs

Affiche des annonces sur ton site ou ton application, et gagne à chaque vue

Les annonces sont choisies, signées et comptées par les serveurs d'Afrolook Ads. Ton code se contente de les afficher : une balise de deux lignes sur un site, un composant prêt à l'emploi dans une application.

Démarrage en 4 étapes

  1. Crée ton profil de diffuseurDans ton espace diffuseur (connexion Google), en acceptant les règles. Notre équipe le valide.
  2. Ajoute ton site ou ton applicationAdresse du site, ou lien Google Play / App Store ; audience mensuelle ; pays ; catégories d'annonces que tu acceptes.
  3. Prouve que le site est à toiAjoute la balise de vérification dans ta page d'accueil, ou le code dans /afrolook-ads.txt.
  4. Reçois ton identifiantAprès validation : ap_xxxxxxxxxx. C'est lui qu'on met dans la balise ou dans l'appel à l'API.
index.html · dans <head>HTML
<meta name="afrolook-ads-verification" content="afv_3k9x…">
ou, dans le fichier /afrolook-ads.txt à la racine du site : afv_3k9x…
!

La balise de vérification doit rester en place : retirée 3 jours de suite, la diffusion est suspendue.

Le clic

GETad.click → https://afrolookmedia.com/ads/api/go?t=…

Le bouton de l'annonce ouvre toujours le lien click : Afrolook Ads compte le clic puis ouvre l'annonceur (le bon magasin selon le téléphone pour une application). N'appelle jamais ce lien toi-même.

✓

Questions fréquentes

Aucune annonce ne s'affiche.

Pas d'annonce pour ce visiteur (pays, langue, appareil), aucune catégorie acceptée, intervalle non écoulé, ou site pas encore validé.

Puis-je mettre la balise sur plusieurs sites ?

Non : un identifiant par site ou application (jusqu'à 10 dans ton espace).

Pourquoi mon audience mesurée est plus basse que la déclarée ?

Nous comptons les personnes différentes pour qui la balise a été chargée. Un écart important et durable fait ajuster l'audience retenue.
