# Consignes pour tout agent (Claude Code ou autre)

**Avant toute chose, lire `docs/PROJET_MEMOIRE.md`** : c'est la mémoire unique du projet (état, décisions, règles métier, plan de migration vers une API Laravel, suivi de ce qui est fait et à faire, journal de bord).

Règles essentielles (détail dans ce fichier) :
- **Poser TOUTES les questions au propriétaire avant de commencer** : ne rien supposer, ne rien décider seul quand une information manque ou qu'un choix existe (voir `docs/PROJET_MEMOIRE.md`, section 8 « Questions ouvertes ») ; consigner ses réponses dans ce fichier.
- Répondre en **français** (accents corrects), simple et direct.
- **Proposer avant d'agir** pour tout changement important ; ne pas committer ni pousser sans demande explicite.
- Aucun secret dans le dépôt ni dans les messages.
- En fin de session : mettre à jour `docs/PROJET_MEMOIRE.md` (cases cochées + une ligne de journal).
- Sécurité : lire `docs/SECURITE_API.md` avant de toucher aux règles, aux paiements, aux comptes ou aux administrateurs.
- Organisation (dossiers, conservation du legacy, trois agents, comptes d'équipe/administrateurs) : `docs/AGENTS_ET_ORGANISATION.md`. **Tout ce que dit le propriétaire est consigné dans la mémoire ; ne rien mettre en place sans l'avoir demandé.**
