titre: SQL : jointures et agrégats
== fiche
p: Pour croiser des tables et calculer des statistiques, on utilise les jointures et les fonctions d'agrégation.
li: JOIN relie deux tables : FROM Etudiant JOIN Note ON Etudiant.id = Note.id_etudiant.
li: INNER JOIN ne garde que les lignes qui ont une correspondance des deux côtés ; LEFT JOIN garde toutes les lignes de la table de gauche.
li: Fonctions d'agrégation : COUNT (nombre de lignes), SUM, AVG (moyenne), MIN, MAX.
li: GROUP BY regroupe les lignes par valeur : SELECT filiere, COUNT(*) FROM Etudiant GROUP BY filiere.
li: HAVING filtre les groupes (après GROUP BY), alors que WHERE filtre les lignes (avant).
li: DISTINCT supprime les doublons dans le résultat.
note: Exemple : SELECT AVG(valeur) FROM Note WHERE matiere = 'Maths' donne la moyenne des notes de maths.
note: Avec GROUP BY, chaque colonne du SELECT doit être soit dans le GROUP BY, soit une fonction d'agrégation.
