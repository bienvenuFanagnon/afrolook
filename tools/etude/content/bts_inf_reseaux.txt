titre: Réseaux informatiques et internet
== fiche
p: Un réseau relie des appareils pour échanger des données. Internet est le plus grand réseau du monde.
li: Types de réseaux : LAN (local, maison ou entreprise), WAN (étendu), Internet ; Wi-Fi : sans fil ; Ethernet : filaire.
li: Matériel : routeur (relie des réseaux, partage la connexion), switch (relie des appareils d'un réseau local), box ou modem (accès internet), point d'accès Wi-Fi.
li: Adresse IP : identifiant d'un appareil sur un réseau ; IPv4 (4 nombres de 0 à 255, ex. 192.168.1.10) ; IPv6 : adresses plus longues.
li: DNS : annuaire qui traduit un nom de site (www.exemple.com) en adresse IP.
li: DHCP : attribue automatiquement les adresses IP aux appareils.
li: Protocoles : HTTP et HTTPS (web, HTTPS est chiffré), FTP (transfert de fichiers), SMTP/IMAP/POP (courriel), TCP/IP (base d'internet).
li: Modèle en couches : modèle OSI en 7 couches ; TCP/IP en 4 couches.
li: Adresse MAC : identifiant matériel de la carte réseau.
li: Serveur web et navigateur : le navigateur demande une page, le serveur la renvoie.
li: Débit : en Mbit/s ; latence : délai de réponse en millisecondes ; bande passante : capacité maximale.
li: Réseaux mobiles : 2G, 3G, 4G, 5G ; VPN : tunnel chiffré qui protège la connexion.
note: Une adresse 192.168.x.x est privée : elle n'est visible que dans le réseau local.
note: Le cadenas HTTPS indique une connexion chiffrée, pas un site forcément honnête.
