titre: Python : les bases
== fiche
p: Python est un langage lisible, très utilisé en sciences, en web et en intelligence artificielle. Le code est structuré par l'indentation.
li: Variables : x = 5 ; nom = "Ama" ; pas de déclaration de type, Python le devine.
li: Types de base : int (entier), float (réel), str (texte), bool (True / False).
li: Affichage : print("Bonjour") ; lecture clavier : input("Nom ? ") renvoie toujours un texte.
li: Conversion : int("12") donne 12 ; str(12) donne "12".
li: Opérateurs : + − * / (division réelle), // (division entière), % (reste), ** (puissance).
li: Condition : if x > 3: … elif … else: … ; boucles : for i in range(5): et while condition:.
note: range(5) donne 0, 1, 2, 3, 4 (5 exclu). range(1, 4) donne 1, 2, 3.
note: Commentaires avec #. L'indentation (4 espaces) délimite les blocs : une mauvaise indentation provoque une erreur.
