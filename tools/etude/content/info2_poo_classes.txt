titre: Classes et objets
== fiche
p: La programmation orientée objet (POO) organise le code autour d'objets qui regroupent des données (attributs) et des comportements (méthodes).
li: Une classe est un modèle ; un objet (ou instance) est un exemplaire créé à partir de la classe.
li: Le constructeur initialise l'objet (en Python : __init__, en Java : méthode portant le nom de la classe).
li: Encapsulation : on protège les attributs (private, protected) et on y accède par des méthodes (getters, setters).
li: Les méthodes agissent sur l'objet (self en Python, this en Java).
li: Attributs de classe (partagés par toutes les instances) et attributs d'instance (propres à chaque objet).
li: Méthode statique : appartient à la classe, appelée sans créer d'objet.
li: Exemple Python : class Compte: def __init__(self, solde): self.solde = solde ; c = Compte(100).
li: Avantages : réutilisation du code, modularité, maintenance facilitée.
note: Exemple : la classe Voiture avec attributs marque et vitesse ; l'objet ma_voiture = Voiture("Toyota", 0).
note: Plusieurs objets d'une même classe ont leurs propres valeurs d'attributs.
