titre: Équations différentielles linéaires
== fiche
p: Une équation différentielle relie une fonction inconnue y à ses dérivées. Les résoudre, c'est trouver toutes les fonctions qui la vérifient.
li: Équation y′ = a y : les solutions sont y = C e^(a x), où C est une constante réelle.
li: Équation y′ + a y = b (a ≠ 0) : solutions y = C e^(−a x) + b/a.
li: Condition initiale : une valeur y(x₀) = y₀ fixe la constante C et donne une solution unique.
li: Équation du second ordre y″ + ω² y = 0 : y = A cos(ω x) + B sin(ω x) (oscillations).
li: Équation y″ − k² y = 0 : y = A e^(k x) + B e^(−k x).
li: Physique : décharge d'un condensateur (y′ = −y/RC), désintégration radioactive (N′ = −λ N), refroidissement d'un corps.
li: Pour vérifier une solution, on la dérive et on remplace dans l'équation.
note: Exemple : y′ = 2y avec y(0) = 3 donne y = 3 e^(2x).
note: Le temps caractéristique de y = e^(−t/τ) est τ ; après 5 τ la valeur est presque nulle.
