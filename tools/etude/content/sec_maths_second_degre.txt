titre: Équations du second degré
== fiche
p: Une équation du second degré s'écrit ax² + bx + c = 0 avec a ≠ 0.
li: Discriminant : Δ = b² − 4ac.
li: Si Δ > 0 : deux solutions réelles x₁ = (−b − √Δ) / (2a) et x₂ = (−b + √Δ) / (2a).
li: Si Δ = 0 : une solution double x = −b / (2a).
li: Si Δ < 0 : aucune solution réelle.
li: Somme et produit des racines : x₁ + x₂ = −b/a et x₁ × x₂ = c/a.
li: Forme factorisée : ax² + bx + c = a(x − x₁)(x − x₂) quand Δ ≥ 0.
li: Signe du trinôme : pour a > 0 il est du signe de a à l'extérieur des racines et du signe contraire entre les racines.
note: Exemple : x² − 5x + 6 = 0 : Δ = 25 − 24 = 1 ; x = (5 ± 1)/2 donc 2 ou 3.
note: Pour x² − 4 = 0, on peut factoriser (x − 2)(x + 2) = 0.
