titre: Variables, types et opérateurs
== fiche
p: Un algorithme est une suite d'instructions précises qui permet de résoudre un problème. Pour manipuler des données, on utilise des variables.
li: Une variable a un nom, un type et une valeur. Elle se déclare puis reçoit une valeur par affectation (←).
li: Types de base : entier (3), réel (3,14), booléen (vrai/faux), caractère ('a') et chaîne de caractères ("bonjour").
li: Opérateurs arithmétiques : + − × / ; DIV donne le quotient entier et MOD le reste de la division entière.
li: Opérateurs de comparaison : =, ≠, <, ≤, >, ≥. Le résultat est un booléen.
li: Opérateurs logiques : ET, OU, NON. A ET B est vrai seulement si A et B sont vrais.
note: Exemple : x ← 7 ; y ← x MOD 2 donne y = 1 (le reste de 7 divisé par 2).
note: L'ordre compte : après x ← 5 puis x ← x + 1, la variable x vaut 6.
