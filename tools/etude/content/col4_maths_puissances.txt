titre: Puissances et calcul littéral
== fiche
p: Une puissance est un produit répété du même facteur : aⁿ = a × a × … × a (n facteurs). a est la base, n l'exposant.
li: a⁰ = 1 (a ≠ 0) ; a¹ = a ; a⁻ⁿ = 1/aⁿ. Exemples : 2³ = 8, 10⁻² = 0,01.
li: Produit de puissances de même base : aᵐ × aⁿ = aᵐ⁺ⁿ. Quotient : aᵐ ÷ aⁿ = aᵐ⁻ⁿ. Puissance de puissance : (aᵐ)ⁿ = aᵐ×ⁿ.
li: Puissance d'un produit : (ab)ⁿ = aⁿ × bⁿ.
li: Écriture scientifique : un nombre s'écrit a × 10ⁿ avec 1 ≤ a < 10 (ex. 4 500 = 4,5 × 10³).
li: Calcul littéral : on remplace des nombres par des lettres. Réduire une expression : 3x + 2x = 5x.
li: Développer : k(a + b) = ka + kb. Identités remarquables : (a + b)² = a² + 2ab + b² ; (a − b)² = a² − 2ab + b² ; (a + b)(a − b) = a² − b².
note: Exemple : 2³ × 2² = 2⁵ = 32 ; (x + 3)² = x² + 6x + 9.
note: Attention : (a + b)² n'est pas égal à a² + b².
