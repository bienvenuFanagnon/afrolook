titre: La cellule et l'ADN
== fiche
p: La cellule est l'unité de base de tous les êtres vivants. Certains organismes n'ont qu'une cellule (bactéries), d'autres des milliards.
li: Cellule animale : membrane plasmique, cytoplasme, noyau, mitochondries. Cellule végétale : en plus, paroi, vacuole et chloroplastes.
li: Cellule eucaryote : noyau délimité par une membrane. Cellule procaryote (bactéries) : pas de vrai noyau.
li: Le noyau contient les chromosomes faits d'ADN. L'ADN (acide désoxyribonucléique) porte l'information génétique.
li: Structure de l'ADN : double hélice formée de deux brins ; les bases azotées s'associent par paires : A avec T, C avec G.
li: Un gène est une portion d'ADN qui code une protéine. Les protéines déterminent les caractères d'un individu.
li: Mitose : division cellulaire qui donne deux cellules filles identiques, avec le même nombre de chromosomes (croissance, renouvellement).
li: Méiose : division qui produit les gamètes avec moitié moins de chromosomes.
note: Exemple : la cellule humaine possède 46 chromosomes ; un gamète n'en possède que 23.
note: L'ADN est découvert comme structure en double hélice par Watson et Crick en 1953.
