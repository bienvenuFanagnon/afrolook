titre: Fonctions de plusieurs variables
== fiche
p: Une fonction de plusieurs variables, par exemple f(x, y), associe un nombre à un couple de réels ; sa représentation est une surface dans l'espace.
li: Dérivée partielle : on dérive par rapport à une variable en gardant les autres constantes. Exemple : f(x, y) = x² y donne ∂f/∂x = 2xy et ∂f/∂y = x².
li: Gradient : vecteur des dérivées partielles ∇f = (∂f/∂x, ∂f/∂y) ; il pointe dans la direction de la plus forte croissance de f.
li: Point critique : un point où ∇f = 0 ; il peut être un minimum, un maximum ou un point selle.
li: Hessienne : matrice des dérivées secondes ; son signe aide à classer les points critiques.
li: Théorème de Schwarz : pour une fonction de classe C², ∂²f/∂x∂y = ∂²f/∂y∂x.
li: Intégrale double : ∬ f(x, y) dx dy ; sur un rectangle, on intègre une variable puis l'autre (théorème de Fubini).
li: Lignes de niveau : courbes où f est constante.
note: Exemple : f(x, y) = x² + y² a un minimum en (0, 0) où ∇f = (0, 0).
note: L'aire d'un domaine D vaut ∬ de D de dx dy.
