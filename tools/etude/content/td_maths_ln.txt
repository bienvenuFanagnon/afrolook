titre: Fonction logarithme népérien
== fiche
p: La fonction ln est définie sur ]0 ; +∞[. C'est la réciproque de la fonction exponentielle : ln(eˣ) = x et e^(ln x) = x.
li: Valeurs : ln 1 = 0 ; ln e = 1.
li: Propriétés : ln(ab) = ln a + ln b ; ln(a/b) = ln a − ln b ; ln(aⁿ) = n·ln a ; ln(1/a) = −ln a.
li: Dérivée : (ln x)′ = 1/x ; donc ln est strictement croissante sur ]0 ; +∞[.
li: Limites : lim ln x = +∞ en +∞ ; lim ln x = −∞ en 0⁺ ; ln x / x tend vers 0 en +∞.
li: Signe : ln x < 0 si 0 < x < 1 ; ln x > 0 si x > 1.
li: Équations : ln a = ln b équivaut à a = b (avec a, b > 0). Toujours vérifier que l'argument est strictement positif.
note: Exemple : ln 8 = ln(2³) = 3 ln 2.
note: Exemple : ln x = 2 donne x = e².
