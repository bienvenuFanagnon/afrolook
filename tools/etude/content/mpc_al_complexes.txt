titre: Nombres complexes
== fiche
p: Un nombre complexe s'écrit z = a + ib, avec a et b réels et i² = −1. a est la partie réelle, b la partie imaginaire.
li: Addition : (a + ib) + (c + id) = (a + c) + i(b + d). Produit : on développe et on remplace i² par −1.
li: Conjugué : z̄ = a − ib. Le produit z × z̄ = a² + b² est un réel positif.
li: Module : |z| = √(a² + b²), c'est la distance de l'origine au point d'affixe z.
li: Forme trigonométrique : z = r(cos θ + i sin θ), avec r = |z| et θ l'argument.
li: Forme exponentielle : z = r e^(iθ) ; le produit de deux complexes multiplie les modules et additionne les arguments.
note: Exemple : (1 + i)(1 − i) = 1 − i² = 2. Le module de 3 + 4i est 5.
note: Formule de Moivre : (cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ).
