titre: Les conditions
== fiche
p: Une structure conditionnelle permet d'exécuter des instructions seulement si une condition est vraie.
li: Forme simple : SI condition ALORS instructions FINSI.
li: Forme avec alternative : SI condition ALORS instructions SINON autres instructions FINSI.
li: Plusieurs cas : SI … SINON SI … SINON … (conditions enchaînées) ou SELON.
li: La condition est une expression booléenne : comparaisons combinées avec ET, OU, NON.
li: Priorité des opérateurs : NON, puis ET, puis OU. Les parenthèses lèvent les ambiguïtés.
note: Exemple : SI note ≥ 10 ALORS écrire("Admis") SINON écrire("Ajourné") FINSI.
note: Une condition mal écrite donne un résultat faux sans erreur visible : teste toujours les cas limites (0, valeurs égales, négatifs).
