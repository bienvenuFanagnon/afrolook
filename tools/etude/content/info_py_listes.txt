titre: Listes, dictionnaires et chaînes
== fiche
p: Python propose des structures pratiques pour regrouper des données.
li: Liste : notes = [12, 15, 9]. Les indices commencent à 0 ; notes[-1] est le dernier élément.
li: Méthodes utiles : append(x) ajoute, remove(x) retire, len(L) donne la taille, sorted(L) trie, sum(L) additionne.
li: Découpage : L[1:3] prend les éléments d'indices 1 et 2 (3 exclu).
li: Dictionnaire : d = {"nom": "Ama", "age": 20}. On lit d["nom"]. Les clés sont uniques.
li: Chaînes : s.upper(), s.lower(), s.split(" "), len(s), s[0]. Une chaîne ne se modifie pas en place.
li: Boucler : for note in notes: ; for cle, valeur in d.items():.
note: Exemple : notes = [12, 15, 9] ; sum(notes) / len(notes) donne la moyenne = 12.0.
note: Un tuple (1, 2) ressemble à une liste mais ne se modifie pas.
