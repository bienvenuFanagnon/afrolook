titre: Coûts et seuil de rentabilité
== fiche
p: Connaître ses coûts permet de fixer ses prix et de savoir à partir de combien de ventes on gagne de l'argent.
li: Charges fixes : indépendantes du volume (loyer, salaires fixes, assurances). Charges variables : proportionnelles au volume (matières, emballages, commissions).
li: Coût total = charges fixes + charges variables. Coût moyen = coût total / quantité.
li: Marge sur coût variable (MCV) = chiffre d'affaires − charges variables ; taux de MCV = MCV / chiffre d'affaires.
li: Seuil de rentabilité (point mort) = charges fixes / taux de MCV (en valeur) ou charges fixes / MCV unitaire (en quantité).
li: Résultat = MCV − charges fixes. Sous le seuil : perte ; au-dessus : bénéfice.
li: Marge de sécurité = chiffre d'affaires − seuil de rentabilité.
li: Coût marginal : coût de la production d'une unité de plus.
note: Exemple : charges fixes 600 000 ; prix 1 000 ; coût variable unitaire 400. MCV unitaire = 600 ; seuil = 600 000 / 600 = 1 000 unités.
note: Pour baisser le seuil de rentabilité, on réduit les charges fixes ou on augmente la marge unitaire.
