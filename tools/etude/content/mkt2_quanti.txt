titre: Études quantitatives et sondages
== fiche
p: Une étude quantitative mesure des comportements ou opinions sur un échantillon et généralise les résultats à une population.
li: Population : l'ensemble des personnes visées ; échantillon : sous-ensemble interrogé ; base de sondage : liste dont on tire l'échantillon.
li: Méthodes probabilistes : tirage aléatoire simple, stratifié, par grappes ; méthodes empiriques : quotas, convenance, boule de neige.
li: Taille et précision : marge d'erreur approximative = 1/√n (n = taille de l'échantillon) ; n = 100 donne environ ± 10 % ; n = 400 environ ± 5 % ; n = 1 000 environ ± 3 %.
li: Questionnaire : questions fermées (réponses prévues), ouvertes (réponses libres), échelles (par exemple de 1 à 5), questions simples, neutres, une idée par question ; pré-test avant diffusion.
li: Modes de collecte : face à face, téléphone, en ligne, via messagerie mobile ; chacun a ses coûts et biais.
li: Biais : échantillon non représentatif, questions orientées, non-réponses, mensonge social, enquêteur.
li: Analyse : tris à plat (pourcentages), tris croisés (selon l'âge, le sexe), moyennes, graphiques.
note: Une étude qualitative (entretiens, groupes de discussion) explore les motivations ; une étude quantitative les mesure.
note: Interroger uniquement ses amis donne un échantillon biaisé.
