titre: Fonctions et fichiers
== fiche
p: Les fonctions rendent le code réutilisable. Les fichiers permettent de garder des données après la fin du programme.
li: Définition : def carre(x): return x * x. Appel : carre(5) donne 25.
li: Sans return, une fonction renvoie None.
li: Paramètres par défaut : def saluer(nom="ami"):. Arguments nommés : saluer(nom="Ama").
li: Variables locales (dans la fonction) et globales (hors des fonctions).
li: Lire un fichier : with open("notes.txt", "r") as f: texte = f.read(). Écrire : mode "w" (écrase) ou "a" (ajoute).
li: with ferme automatiquement le fichier.
li: Les erreurs se gèrent avec try: … except ValueError: ….
note: Exemple : int("abc") lève une ValueError ; try / except permet de l'attraper sans arrêter le programme.
note: Une bonne fonction fait une seule chose et porte un nom clair.
