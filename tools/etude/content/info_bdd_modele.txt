titre: Le modèle relationnel
== fiche
p: Une base de données organise l'information pour la retrouver et la modifier facilement. Le modèle relationnel la range dans des tables.
li: Une table est faite de lignes (enregistrements) et de colonnes (attributs ou champs).
li: Une clé primaire identifie de façon unique chaque ligne (ex. numéro d'étudiant). Elle ne peut pas être vide ni répétée.
li: Une clé étrangère est une colonne qui renvoie à la clé primaire d'une autre table : elle crée le lien entre les tables.
li: Une relation peut être un-à-plusieurs (un enseignant, plusieurs cours) ou plusieurs-à-plusieurs (étudiants et cours, via une table de liaison).
li: Normaliser, c'est éviter de répéter les mêmes informations à plusieurs endroits.
li: Un SGBD (MySQL, PostgreSQL, SQLite…) est le logiciel qui gère les bases.
note: Exemple : table Etudiant(id, nom, filiere) avec id clé primaire ; table Note(id_etudiant, matiere, valeur) où id_etudiant est une clé étrangère vers Etudiant.
note: Règle : jamais deux lignes avec la même clé primaire.
