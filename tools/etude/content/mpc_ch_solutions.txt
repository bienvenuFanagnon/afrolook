titre: Solutions, concentrations et acides-bases
== fiche
p: Une solution est un mélange homogène d'un soluté dissous dans un solvant (souvent l'eau).
li: Concentration molaire : C = n / V, en mol/L. Quantité de matière : n = m / M (M masse molaire en g/mol).
li: Dilution : C₁ V₁ = C₂ V₂ (la quantité de matière de soluté ne change pas).
li: pH = −log [H₃O⁺]. pH < 7 : solution acide ; pH = 7 : neutre (à 25 °C) ; pH > 7 : basique.
li: Acide : espèce qui cède un proton H⁺ ; base : espèce qui capte un proton.
li: Un acide fort réagit totalement avec l'eau (HCl) ; un acide faible partiellement (acide éthanoïque).
li: Dosage acido-basique : à l'équivalence, la quantité d'acide égale celle de base (n_A = n_B quand les coefficients sont 1).
note: Exemple : 0,2 mol dissoute dans 0,5 L donne C = 0,4 mol/L.
note: Masses molaires : H = 1, C = 12, O = 16, Na = 23, Cl = 35,5 g/mol ; l'eau H₂O vaut 18 g/mol.
