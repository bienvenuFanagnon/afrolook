titre: Listes, piles et files
== fiche
p: Une structure de données organise des informations pour les stocker et les retrouver efficacement.
li: Tableau : éléments contigus en mémoire, accès direct par indice en temps constant O(1), insertion au milieu coûteuse O(n).
li: Liste chaînée : chaque élément (nœud) contient une valeur et un pointeur vers le suivant. Insertion en tête en O(1), accès à un élément en O(n).
li: Pile (stack) : LIFO, dernier entré, premier sorti. Opérations : empiler (push), dépiler (pop), sommet (peek).
li: File (queue) : FIFO, premier entré, premier sorti. Opérations : enfiler (enqueue), défiler (dequeue).
li: Usages : pile pour l'historique « annuler », la gestion des appels de fonctions, l'évaluation d'expressions ; file pour les tâches à traiter dans l'ordre d'arrivée (impression, attente).
li: Complexité : O(1) constant, O(log n) logarithmique, O(n) linéaire, O(n²) quadratique.
li: Table de hachage (dictionnaire) : accès moyen en O(1) grâce à une fonction de hachage.
note: Exemple : empiler 1, 2, 3 puis dépiler donne 3 en premier (LIFO). Enfiler 1, 2, 3 puis défiler donne 1 en premier (FIFO).
note: En Python, une liste sert souvent de pile (append et pop) ; collections.deque convient pour une file.
