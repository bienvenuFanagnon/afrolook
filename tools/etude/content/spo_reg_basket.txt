titre: Le basket-ball : règles essentielles
== fiche
p: Le basket-ball oppose deux équipes de cinq joueurs qui cherchent à envoyer le ballon dans le panier adverse.
li: Le panier est à 3,05 mètres du sol. Un match comprend quatre quart-temps de 10 minutes (règles FIBA).
li: Points : 1 point pour un lancer franc, 2 points pour un tir à l'intérieur de l'arc, 3 points pour un tir derrière la ligne à trois points.
li: Le joueur qui a le ballon doit dribbler (faire rebondir le ballon) pour se déplacer ; marcher avec le ballon est une faute de marcher.
li: Reprise de dribble : après avoir arrêté son dribble, un joueur ne peut pas redribbler (double dribble).
li: Règle des 24 secondes : l'équipe doit tenter un tir dans les 24 secondes après avoir pris le ballon.
li: Fautes personnelles : un joueur exclu après cinq fautes. Lancers francs accordés pour une faute sur un tireur ou après un nombre de fautes d'équipe.
li: Passes, dribbles, tirs, rebonds et interceptions sont les gestes de base ; le jeu de passes collectif est essentiel.
note: Le basket a été inventé en 1891 par James Naismith, aux États-Unis.
note: La Fédération internationale est la FIBA ; la ligue américaine est la NBA.
