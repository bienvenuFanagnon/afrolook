titre: Systèmes d'exploitation et bureautique
== fiche
p: Le système d'exploitation fait le lien entre le matériel et les programmes. La bureautique reste la compétence la plus demandée au quotidien.
li: Système d'exploitation (OS) : logiciel principal qui gère le matériel et les programmes ; exemples : Windows, Linux, macOS, Android, iOS.
li: Fichier et dossier : un fichier a un nom et une extension (.docx, .xlsx, .pdf, .jpg, .mp3) ; un dossier range des fichiers.
li: Logiciel et application : programme qui accomplit une tâche ; open source : code ouvert et souvent gratuit (Linux, LibreOffice).
li: Traitement de texte (Word) : mise en forme, styles, tableaux, table des matières, mailing.
li: Tableur (Excel) : cellules, formules (=SOMME(A1:A5), =MOYENNE, =SI), références absolues $A$1, tableaux croisés dynamiques, graphiques.
li: Présentation (PowerPoint) : diapositives, transitions, modèles ; règle : peu de texte par diapositive.
li: Raccourcis : Ctrl+C (copier), Ctrl+V (coller), Ctrl+X (couper), Ctrl+Z (annuler), Ctrl+S (enregistrer).
li: Sauvegarde : copie de ses fichiers sur un autre support ou dans le cloud ; règle 3-2-1 : trois copies, deux supports, une hors site.
li: Cloud : stockage et services accessibles par internet (Google Drive, OneDrive).
li: Mise à jour : corrige les failles et ajoute des fonctions ; ne jamais l'ignorer trop longtemps.
note: Une formule Excel commence toujours par le signe égal.
note: Teste ta sauvegarde : une copie jamais restaurée n'est pas fiable.
