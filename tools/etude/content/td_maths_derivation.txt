titre: Dérivation et étude de fonctions
== fiche
p: La dérivée f′(x) mesure la pente de la courbe en x. Elle sert à étudier les variations d'une fonction.
li: Dérivées usuelles : (xⁿ)′ = n·xⁿ⁻¹ ; (constante)′ = 0 ; (√x)′ = 1/(2√x) ; (1/x)′ = −1/x².
li: Opérations : (u + v)′ = u′ + v′ ; (k·u)′ = k·u′ ; (u·v)′ = u′v + uv′ ; (u/v)′ = (u′v − uv′)/v².
li: Signe de f′ : si f′(x) > 0 sur un intervalle, f est croissante ; si f′(x) < 0, f est décroissante.
li: Un extremum local apparaît quand f′ s'annule en changeant de signe.
li: Tangente en a : y = f′(a)(x − a) + f(a).
li: Étude complète : domaine, limites, dérivée, tableau de variations, tangentes, courbe.
note: Exemple : f(x) = x² − 4x. f′(x) = 2x − 4, qui s'annule en x = 2. f est décroissante avant 2 puis croissante : minimum f(2) = −4.
note: Ne pas confondre : (u·v)′ n'est pas u′·v′.
