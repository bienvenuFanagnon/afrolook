titre: Théorème de Thalès
== fiche
p: Le théorème de Thalès compare les longueurs de deux triangles dont les côtés sont parallèles.
li: Configuration : deux droites (BM) et (CN) sécantes en A, avec (BC) // (MN). A, B, M alignés et A, C, N alignés.
li: Théorème : si (BC) // (MN), alors AB/AM = AC/AN = BC/MN.
li: On utilise l'égalité pour calculer une longueur inconnue : produit en croix.
li: Réciproque : si AB/AM = AC/AN avec les points alignés dans le même ordre sur les deux droites, alors (BC) // (MN).
li: Pour montrer que deux droites ne sont pas parallèles, on montre que les rapports sont différents.
li: Agrandissement et réduction : un rapport k multiplie les longueurs par k et les aires par k².
note: Exemple : AB = 3, AM = 6, AC = 4. Alors AN = AC × AM / AB = 4 × 6 / 3 = 8.
note: Il faut toujours vérifier que les droites sont bien parallèles avant d'appliquer Thalès.
